# Zenthium Heroes: Design

Status: pre-GDD design. No build plan yet.

## Core concept
- Top-down 2D superhero game inspired by comic book, DCU and MCU universes.
- Mission-based, with roguelite progression.
- The hero organization is **SWIFT** (it matches the stat acronym; see `stats.md`).
- **Rewards:** Zenny crystals in many colors (red, blue, gold, sapphire, etc.), in crystal and metallic variants. All shiny.
- **Progression:** spend Zenny in Create-a-Hero (CAH). See `heroes.md`.

## Files
| File | Covers |
|---|---|
| `heroes.md` | Hero roster, CAH, slots, reward balance |
| `stats.md` | SWIFT stats, secondary stats, combat rules, Defiance |
| `time.md` | Timescale, time powers, cooldown tags |
| `modules.md` | Module schema, tags, triggers, full module catalog |
| `missions.md` | Mission flow, types, secondary goals, citizens, extraction |
| `factions.md` | Villain factions and their units |
| `hq.md` | HQ between missions and its tabs |

Each file ends with an `## Open` section for its unresolved questions.
