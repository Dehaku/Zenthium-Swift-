# Controls

Mouse and keyboard, and gamepad.

| Action | Mouse and keyboard | Gamepad |
|---|---|---|
| Move | WASD | Left stick |
| Aim | Mouse | Right stick |
| Active power slots 1-4 | LMB, RMB, Q, E | RT, RB, LT, LB |
| Gear actives 1-4 | 1, 2, 3, 4 | D-pad |
| Kick | Space | A |
| Drag | F | X |
| Sprint (toggle) | Left Shift | L3 |
| Module "more info" (hold) | Left Alt | Y |
| Friendly fire (hold) | Left Ctrl | B |
| Pause | Esc | Start |
| Skip start sequence | Hold any button 1 s | Hold any button 1 s |

- Gamepad powers sit on the triggers and bumpers so the right thumb can stay on the aim stick.
