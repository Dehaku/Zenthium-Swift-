# Luck

- Every random roll a character makes uses their Luck.
- Base 100%. Usually moves in 10% steps. Can go negative.
- Each roll uses Luck differently. This file is the config: every roll Luck affects, and by how much.
- Super Lucky (`modules.md`) aims for roughly 10x better outcomes, for example 10x as likely to dodge.
