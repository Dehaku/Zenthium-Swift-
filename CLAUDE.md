# Editing rules
- Design lives in `design/`, one topic per file. `design/README.md` is the index.
- To change something, read and edit only the file that owns it. Don't read other files unless the change touches them.
- State each fact once. Other files point to it by filename instead of repeating it.
- Delete superseded ideas instead of keeping history; git has the history.
- Put unresolved questions in the owning file's `## Open` section.
- Ideas parked for later go in `design/future.md`.
- Pure flavor goes in `design/lore.md`; keep mechanics out of it.
- Each Story Arc gets its own file in `design/StoryArcs/`; the rules stay in `design/story.md`.
